# 天机AI选品 · Demo

亚马逊**超级产品开发辅助工具**前端演示：用一套弹力手表表带案例数据，复刻「天机AI选品」工作流的 9 个模块。

> 演示数据为示意，不代表真实市场结果，也不构成采购/合规/法律建议。

## 模块

| Tab | 内容 |
|---|---|
| 概览 | 样本摘要、本品问题/品类共性、最高分升级方案 |
| ① 细分市场 | 形态分组质检 + $2 价格档（含「我在这」） |
| ④ 对标与元素 | 本品/对手/头部常青元素卡，含可迁移标签 |
| ④ 属性矩阵 | 销量拉动、空白格（拉动≥1.3 且产品占比≤25%） |
| ⑤ 差评死法 | 我 vs 对标热力表，点击行看买家原话 |
| ⑥ 差距矩阵 | 他有我无 / 他有我弱 / 他无我有 / 双方都无 |
| ⑦⑧ 升级方案 | 权重可调，资源匹配滑杆，分数即时重算 |
| 成本与包装 | 成本输入 + 单件经济账（缺采购价会提示） |
| ⑨ 假设卡 | 6 张结构化假设卡（人群/变量/验证/止损） |

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

```bash
npm run build    # 生产构建
npm run preview  # 预览构建产物
```

## 技术栈

- Vite + React 19 + TypeScript
- Tailwind CSS v4
